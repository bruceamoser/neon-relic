Evidence Report — Unidentified Metallic Object

PRELIMINARY ASSESSMENT. Artifact not in custody. Analysis based on witness descriptions and indirect indicators only.

DesignationUnidentified Metallic Object — Provisional designation: "Gold Coin" (Object of Interest: Staffordshire)
Physical Description (Witness-Based)Based on contradictory witness accounts from Plough and Furrow pub regulars: a gold-colored coin, estimated 2–2.5 cm diameter. Multiple witnesses describe the object as "warm" to the touch — one witness reportedly attempted to bite the object to verify gold content (standard folk test for gold authenticity — gold is soft and will dent). The coin's obverse (front face) and reverse (back) designs are inconsistently described by witnesses. The object's material is unconfirmed — gold color may indicate gold, gold alloy, gilding, or a different metal altogether. Weight: unknown — no witness provided a weight estimate. Condition: described as intact with clear detail, suggesting limited wear or corrosion. This is notable — gold does not corrode, but Anglo-Saxon gold objects typically show some surface wear from burial. The object is not in custody. Physical examination has not been conducted.
Provenance (Preliminary)The object was reportedly discovered by farmer Arthur Dunn in his north field in rural Staffordshire, approximately two to three weeks ago. Discovery circumstances: reportedly struck by a plough at an estimated depth of 1–1.5 meters. The discovery location is within the geographical area of the anomalous environmental indicators currently under investigation. The object's archaeological context — if it is genuinely an Anglo-Saxon artifact — would place it within the same regional material culture as the Staffordshire Hoard (discovered 1984, approximately 3–5 km from Dunn's farm). The object does not appear in the Staffordshire Hoard catalogue (Birmingham Museum) — it was not among the documented finds. Its relationship to the hoard, if any, is unknown. The object's current location is unknown — last seen in the possession of Arthur Dunn, who is currently unaccounted for.

Anomalous Characteristics (Witness-Reported)

Multiple witnesses independently describe the object as "warm" to the touch. For a metal object — particularly gold — this is anomalous. Metals typically equilibrate with ambient temperature. A metal object that feels warm in a cool English pub suggests either: the object had been held close to the body prior to handling (mundane explanation); the object generates or retains heat independent of ambient conditions (anomalous); or the sensation of warmth is subjective and unreliable (witness error). The warmth has not been instrument-verified.

The witness who attempted to bite the object to verify gold content provides indirect evidence that the object is metallic and possibly gold (gold is soft enough to dent with teeth). However, this test is folk practice, not scientific analysis. Laboratory metallurgical analysis would be required for confirmation.

The object's apparent lack of corrosion after burial — if it is gold — is consistent with gold's chemical properties. If the object is not gold, the lack of corrosion would be anomalous and may indicate an unusual alloy or environmental conditions at the burial site.

Handling Advisory

Recommendation: If the object is located, handle with gloved hands using standard artifact protocols. The reported thermal anomaly — if confirmed — should be treated as an indicator that the object may not be inert. Contain in a sealed, labeled evidence container. Do not attempt to clean, polish, or alter the object. Do not attempt to verify gold content through destructive testing.

The object should not be removed from the region without authorization. Its discovery location — the north field — is the epicenter of anomalous environmental indicators. The relationship between the object and these indicators is unknown but the temporal coincidence (discovery followed by onset of anomalies) is noted. The object may have contextual significance that would be lost if removed from the region.

Advisory: This object has not been physically examined. All characteristics are based on unverified witness testimony. Treat with caution. Await specialist analysis if the object is acquired.

Investigation Status

The object is not in custody. Its last known possessor (Arthur Dunn) is unaccounted for. The object's current location is unknown. It may be: in Dunn's possession at an unknown location; sold or transferred to an unknown party; or still on or near the discovery site (unlikely — preliminary site assessment did not locate it). Locating the object is a priority investigative objective, secondary to locating Dunn himself.

If the object is a genuine Anglo-Saxon artifact, it falls under the UK Treasure Act 1996, which requires finders to report discoveries to authorities. Dunn does not appear to have made such a report. The object's legal status — if it is treasure — would complicate custody.

This report is a preliminary evidence assessment only. Conclusions are provisional.
